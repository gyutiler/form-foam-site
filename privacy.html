개인정보 처리방침

FORM FOAM(폼폼)은 폼폼메모 Windows 앱과 이 홈페이지에서 다루는 정보에 대해 아래와 같이 안내합니다.

시행일: 2026년 10월 6일 · 확인된 앱 버전: 0.6.33 시험판

간단히 보기

메모는 기본적으로 사용자의 PC에 저장됩니다. 앱은 회원가입이나 FORM FOAM 계정을 요구하지 않습니다. Google Drive 연동은 사용자가 직접 연결한 경우에만 동작하며, 이때 메모와 동기화 정보는 사용자의 Google Drive에 저장됩니다.

1. 처리 주체와 문의

서비스 안내 주체: FORM FOAM(폼폼)
개인정보 관련 문의: mattworker0@gmail.com

서비스 문의 이메일을 보내면 답변을 위해 발신 주소와 사용자가 이메일에 직접 적은 정보가 이메일 제공자와 수신 메일함에 전달됩니다. 홈페이지에는 문의 입력 양식이 없으며, 사용자의 메일 앱에서 이메일을 작성하도록 연결합니다.

2. 폼폼메모 앱이 다루는 정보

  • 메모와 설정: 메모 본문, 제목, 분류, 날짜와 앱 설정은 기본적으로 이 Windows PC의 앱 데이터 영역에 저장됩니다.
  • Google Drive 연결: 사용자가 앱에서 Google 계정을 연결하면, 앱은 메모 동기화에 필요한 Drive 파일과 동기화 정보를 Google Drive API로 읽고 씁니다. 앱 설정은 drive.file 범위만 요청하도록 구성되어 있습니다. 메모가 FORM FOAM이 운영하는 중계 서버를 거치도록 구현되어 있지는 않습니다.
  • 인증 정보: Windows 앱의 Google Drive 갱신 토큰은 이 PC의 앱 데이터에 저장되며 Windows DPAPI로 보호됩니다. 로그인 및 동의는 Google 화면에서 사용자가 직접 진행합니다.

Drive 연결을 사용하면 Google이 계정 및 API 이용 정보를 자체 정책에 따라 처리할 수 있습니다. Google 계정 연결과 저장된 Drive 파일은 앱에서 연결 해제하거나 Google 계정의 권한 설정에서 관리할 수 있습니다.

3. 홈페이지 및 앱 분석

이 홈페이지에는 회원가입, 결제, 광고, 분석 추적 기능이 없습니다. 문의는 이메일 링크를 통해 사용자의 메일 앱에서 직접 작성합니다. 정적 호스팅 서비스는 사이트 제공 과정에서 접속 정보를 처리할 수 있으므로, 실제 공개 시 이용하는 호스팅 서비스의 개인정보 안내도 확인해 주세요.

확인한 Windows 앱 구성에서는 개발자 분석·광고 SDK를 사용하도록 설정한 항목을 찾지 못했습니다. 외부 플랫폼이 자체적으로 처리하는 데이터에는 해당 플랫폼의 정책이 적용됩니다.

4. 보관과 삭제

로컬 메모는 앱을 사용하는 동안 PC의 앱 데이터에 남으며, 사용자가 앱 기능으로 정리하거나 PC에서 앱 데이터를 직접 삭제할 수 있습니다. Drive에 저장된 정보는 사용자가 Google Drive에서 직접 관리할 수 있습니다. 앱 제거만으로 로컬 메모나 Drive 파일이 항상 삭제되는 것은 아닙니다.

문의 이메일은 문의 처리와 후속 응대에 필요한 기간 동안 메일함에 보관될 수 있습니다. 보관 기간 또는 삭제 요청은 위 이메일로 문의할 수 있습니다.

5. 방침 변경

앱의 기능, 연결 서비스 또는 홈페이지 제공 방식이 변경되면 이 방침을 갱신하고 시행일을 표시합니다. 기능별 처리 범위는 앱 버전에 따라 달라질 수 있으므로 최신 방침을 확인해 주세요.

이 문서는 서비스 안내입니다.

개인정보 보호 법률 준수 여부에 대한 보증이나 법률 자문이 아닙니다. 공개 전에 실제 배포 앱, Google OAuth 동의 화면, Android 버전, 호스팅 설정을 다시 확인해야 합니다.
